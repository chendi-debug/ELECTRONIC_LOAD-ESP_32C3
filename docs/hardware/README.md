## 选型关注点

### 模拟信号链

- 运放的供电范围和输入共模范围必须覆盖实际采样电压。
- 检查输入失调电压、温漂、噪声和带宽是否满足电压/电流测量精度。
- 输出摆幅需要与 CH32V307 的 ADC 输入范围及后级参考电压匹配。
- 布板时让采样回路远离开关电源、电感和大电流功率回路，并保证模拟地回流路径清晰。

### 电源转换

- 按最大输入电压、输出电流、效率和温升留出设计余量。
- 电感、肖特基二极管、输入/输出电容应依据规格书的推荐范围选择。
- 开关节点走线应短而紧凑，避免开关噪声耦合到 ADC 和运放信号。
- 调试时依次确认 12 V、5 V、3.3 V 及模拟参考电压，再连接 MCU 和负载级。

### MOSFET 与驱动

- 核对栅源电压、漏源耐压、持续电流和导通电阻。
- AO3400A 属于外围小功率开关器件，不能替代电子负载功率级的大功率 MOSFET。
- 感性负载或风扇驱动需要检查续流和浪涌保护设计。

## 使用说明

规格书是设计参考，实际采购前仍应核对器件后缀、封装、温度等级和供应商页面。若使用替代型号，应重新验证引脚兼容性、供电范围、关键电气参数、散热和闭环稳定性。
