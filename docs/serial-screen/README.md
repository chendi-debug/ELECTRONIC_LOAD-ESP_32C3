# 串口屏工程与资源

本目录保存电子负载串口屏的界面工程、图片/字体资源、示例代码和演示视频。串口屏负责显示电压、电流、功率、工作模式、电池状态及测试结果，并接收用户的设置操作。

## 文件说明

| 内容 | 说明 |
| --- | --- |
| `test.HMI` | 串口屏主界面工程文件 |
| `test1.HMI` | 串口屏另一版/测试版工程文件 |
| `电子负载copy/` | 页面工程拆分后的图片、字体和组件资源 |
| `sine_wave.c` | 波形/串口屏相关 C 示例代码 |
| 根目录 `.png` 文件 | 串口屏页面截图和界面素材 |
| `6月4日 (1)(1).mp4` | 串口屏及整机运行演示视频 |

## 使用方法

1. 使用与该屏幕型号匹配的串口屏编辑器打开 `.HMI` 工程。
2. 检查工程中的图片、字体和控件资源是否完整；`电子负载copy/` 中保留了原始资源文件。
3. 编译生成屏幕固件并下载到串口屏。
4. 将串口屏连接到 CH32V307 对应的 HMI 串口，波特率和通信协议以 `CH32V307/README.md` 及固件源码为准。

`.HMI` 文件属于工程源文件，图片和 `.zi` 文件属于资源文件；不同串口屏编辑器版本可能对资源格式和下载方式有要求。
